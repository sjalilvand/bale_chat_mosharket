# Bale Chat Mosharket | دسته‌بندی پیام‌های گروه بله

برنامه **وب‌محور (Flask + HTML)** برای **دریافت، دسته‌بندی و ساخت گزارش HTML** از پیام‌های گروه‌های پیام‌رسان **بله** — با داشبورد مدرن، نوار پیشرفت زنده و درصد پیشرفت پروژه.

- داشبورد وب زیبا (راست‌به‌چپ، فونت وزیرمتن، طراحی مدرن)
- الهام‌گرفته از [AtharNaemi/bale_chat_backup](https://github.com/AtharNaemi/bale_chat_backup)؛ خروجی CSV آن ابزار مستقیماً قابل ورود است
- بر پایه API رسمی ربات‌های بله ([docs.bale.ai](https://docs.bale.ai))

## قابلیت‌ها (نسخه ۳)

- **خواندن همه انواع محتوا:** عکس، آلبوم عکس، ویدیو، ویس، آهنگ، فایل، استیکر، کپشن زیر عکس‌ها
- **کامنت‌ها و پاسخ‌ها** به‌صورت تو در تو زیر پیام اصلی نمایش داده می‌شوند
- **نشان بازنشر (فوروارد)** — منبع پست‌های بازنشرشده از کانال‌ها و گروه‌های دیگر مشخص است
- **دانلود خودکار عکس‌ها** در پوشه `media/` و نمایش داخل گزارش (تصاویر داخل فایل HTML جاسازی می‌شوند تا گزارش تک‌فایلی بماند)
- **افزودن گروه با لینک دعوت** (`ble.ir/join/...`)، شناسه عددی یا نام‌کاربری؛ با راهنمای گام‌به‌گام برای اضافه‌کردن ربات به گروه
- ذخیره پیام‌هایی که به چت ربات **فوروارد می‌شوند** (برای انتقال تاریخچه قدیمی)
- **حلقه درصد پیشرفت پروژه** با چک‌لیست زنده ۶ مرحله (اتصال، گروه، شروع، قوانین، خواندن، گزارش)
- **نوار «روند پیشرفت خواندن»** با درصد و هدف قابل تنظیم
- **لاگ زنده پیام‌ها** — هر پیام لحظه ورود نمایش داده می‌شود
- آمار زنده: کل پیام‌ها، شرکت‌کنندگان، عکس‌ها، کل رسانه‌ها، این نشست، دسته‌ها
- قوانین دسته‌بندی کلیدواژه‌ای قابل ویرایش (اعمال فوری روی پیام‌های ذخیره‌شده)
- **گزارش HTML تک‌فایلی**: آمار، نمودار توزیع دسته‌ها، فیلتر دسته‌ها، تاریخ شمسی، گالری عکس
- ورود پیام‌های قدیمی از CSV (خروجی bale_chat_backup) یا JSON
- جلوگیری از ثبت تکراری پیام‌ها + بازیابی تنظیمات پس از ری‌استارت

نسخه دسکتاپ قدیمی (Tkinter) هم همچنان موجود است: `python gui.py`

## نصب و اجرا

پایتون ۳.۸+ (در ویندوز، هنگام نصب پایتون گزینه tcl/tk پیش‌فرض فعال است):

```bash
pip install -r requirements.txt
python main.py
```

مرورگر به‌صورت خودکار روی `http://127.0.0.1:5000` باز می‌شود.

## مراحل استفاده در داشبورد

1. **اتصال ربات:** توکن BotFather را وارد و «اتصال» را بزنید.
2. **انتخاب گروه:** لینک گروه یا شناسه را در کادر «افزودن گروه» وارد کنید.
   - **مهم:** ربات‌های بله (مثل تلگرام) اجازه ندارند با لینک دعوت وارد گروه شوند؛ لینک فقط برای افراد است. راهنمای گام‌به‌گام در خود برنامه نمایش داده می‌شود:
     ۱) تنظیمات گروه → «افزودن عضو» → انتخاب `@mosharkat_bot` → ۲) ادمین کردن ربات → ۳) دکمه «شناسایی گروه‌ها».
   - اگر شناسه عددی گروه را دارید (مثل `-1001234567890`) مستقیم وارد کنید تا انتخاب شود.
3. **قوانین دسته‌بندی:** دسته‌ها و کلیدواژه‌ها را ویرایش و «اعمال» کنید. قالب هر خط: `نام دسته: کلیدواژه۱، کلیدواژه۲`
4. **دریافت پیام‌ها:** «شروع دریافت» را بزنید؛ نوار پیشرفت و لاگ زنده، روند خواندن را نشان می‌دهند. عکس‌ها خودکار دانلود می‌شوند.
5. **گزارش HTML:** «ساخت گزارش» را بزنید؛ خروجی در تب جدید باز می‌شود (مسیر: `output/report.html`) — شامل عکس‌ها، کپشن‌ها و کامنت‌ها.

## پیام‌های قدیمی چه می‌شوند؟

ربات‌های بله فقط پیام‌های **جدید** را دریافت می‌کنند و به تاریخچه قبل از ورودشان دسترسی ندارند (سرور بله فقط آخرین ۲۰۰۰ آپدیت را تا ۲۴ ساعت نگه می‌دارد). دو راه دارید:

**راه ۱ — فوروارد به ربات (ساده):** پیام‌های قدیمی گروه را از داخل بله به چت خصوصی ربات فوروارد کنید؛ این نسخه متن، عکس و کپشن آن‌ها را ذخیره می‌کند.

**راه ۲ — خروجی CSV:**
1. با ابزار [bale_chat_backup](https://github.com/AtharNaemi/bale_chat_backup) از نسخه وب بله خروجی CSV بگیرید.
2. در داشبورد، دکمه **«ورود پیام‌های قدیمی (CSV/JSON)»** را بزنید و فایل‌های `بخش_*.csv` را انتخاب کنید.
3. حالا گزارش شامل پیام‌های قدیمی + جدید خواهد بود.

## نکات امنیتی

- **توکن ربات را در کد یا ریپوی عمومی قرار ندهید.** توکن فقط در `settings.json` روی سیستم شما ذخیره می‌شود (در `.gitignore` است).
- اگر توکن جایی لو رفت، از BotFather بخواهید آن را ریست (Revoke) کند.

## عیب‌یابی

- **ربات پیام‌های گروه را نمی‌بیند:** ربات را ادمین کنید و در گروه پیام جدید بفرستید، سپس «شناسایی گروه‌ها» را دوباره بزنید.
- **گروه با لینک اضافه نمی‌شود:** این محدودیت بله است — ربات با لینک دعوت عضو نمی‌شود؛ ربات را دستی به گروه اضافه کنید (راهنما در خود برنامه هست).
- **عکس‌های پیام‌های قبلی دانلود نشد:** فقط عکس پیام‌هایی که بعد از فعال‌بودن «شروع دریافت» می‌رسند دانلود می‌شود؛ پیام‌های قدیمی‌تر از سرور قابل بازیابی نیستند.
- **گزارش فارسی به‌هم‌ریخته است:** فونت وزیرمتن از اینترنت بارگذاری می‌شود؛ در نبود اینترنت Tahoma جایگزین می‌شود.
