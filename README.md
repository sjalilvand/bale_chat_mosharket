# Bale Chat Mosharket | دسته‌بندی پیام‌های گروه بله

برنامه گرافیکی برای **دریافت، دسته‌بندی و ساخت گزارش HTML** از پیام‌های گروه‌های پیام‌رسان **بله** — بر پایه API رسمی ربات‌های بله ([docs.bale.ai](https://docs.bale.ai)).

الهام‌گرفته از پروژه [AtharNaemi/bale_chat_backup](https://github.com/AtharNaemi/bale_chat_backup)؛ فایل‌های CSV خروجی آن ابزار مستقیماً در همین برنامه قابل ورود هستند.

## قابلیت‌ها

- رابط گرافیکی (Tkinter) — بدون نیاز به خط فرمان
- وارد کردن توکن ربات بله + دکمه تست اتصال
- شناسایی خودکار گروه‌ها از پیام‌های اخیر ربات، یا افزودن دستی با شناسه گروه
- دریافت خودکار پیام‌های جدید (long polling) و ذخیره در `messages.json`
- دسته‌بندی کلیدواژه‌ای با قوانین کاملاً قابل ویرایش داخل برنامه
- ساخت گزارش **HTML تک‌فایلی** با آمار کلی، نمودار توزیع دسته‌ها، فیلتر دسته‌ها و **تاریخ شمسی**
- ورود پیام‌های **قدیمی** از خروجی CSV ابزار bale_chat_backup یا فایل JSON
- جلوگیری از ثبت تکراری پیام‌ها (offset + شناسه آپدیت)

## نصب و اجرا

پایتون ۳.۸ یا بالاتر لازم است (در ویندوز، هنگام نصب پایتون گزینه tcl/tk پیش‌فرض فعال است):

```bash
pip install -r requirements.txt
python main.py
```

## مراحل استفاده

1. در بله به **BotFather@** پیام دهید و با دستور `/newbot` یک ربات بسازید و توکن را کپی کنید.
2. برنامه را باز کنید؛ در تب **«تنظیمات ربات»** توکن را وارد و **«تست اتصال»** را بزنید.
3. ربات را **به گروه اضافه کنید** (ترجیحاً ادمین کنید تا همه پیام‌ها را ببیند).
4. در گروه یک پیام بفرستید، سپس در تب **«گروه»** روی **«شناسایی گروه‌ها»** بزنید و گروه را انتخاب کنید. (یا شناسه گروه را دستی وارد کنید.)
5. در تب **«دسته‌بندی»** قوانین را ویرایش کنید و **«اعمال و ذخیره»** را بزنید.
6. در تب **«دریافت پیام»** روی **«شروع دریافت»** بزنید؛ پیام‌های جدید لحظه‌ای ذخیره می‌شوند.
7. در تب **«گزارش HTML»** روی **«ساخت گزارش»** بزنید تا فایل خروجی ساخته و در مرورگر باز شود.

### قالب قوانین دسته‌بندی

هر خط یک دسته؛ کلیدواژه‌ها با ویرگول (`,` یا `،` یا `|`) جدا می‌شوند:

```
اطلاعیه: اطلاعیه، اعلام، هماهنگ
جلسه و قرار: جلسه، قرار، حضوری
پرسش و پاسخ: ؟, ?, چرا، چطور، سوال
سفارش و امور مالی: سفارش، خرید، قیمت، فاکتور، پرداخت
```

پیام‌هایی که هیچ کلیدواژه‌ای نداشته باشند به دسته **«سایر»** می‌روند.

## پیام‌های قدیمی چه می‌شوند؟

ربات‌های بله فقط پیام‌های **جدید** را دریافت می‌کنند و به تاریخچه قبل از ورودشان دسترسی ندارند. برای پیام‌های قدیمی:

1. با ابزار [bale_chat_backup](https://github.com/AtharNaemi/bale_chat_backup) از نسخه وب بله خروجی CSV بگیرید (فایل‌های `بخش_*.csv` در پوشه `bale_backups`).
2. در همین برنامه، تب **«دریافت پیام»** → دکمه **«ورود فایل CSV»** → همه فایل‌ها را انتخاب کنید.
3. اکنون گزارش HTML شامل پیام‌های قدیمی + جدید خواهد بود.

## نکات امنیتی

- **توکن ربات را در کد یا ریپوی عمومی قرار ندهید.** برنامه توکن را فقط در حافظه نگه می‌دارد؛ با فعال کردن گزینه «ذخیره توکن» در `settings.json` روی سیستم خودتان ذخیره می‌شود که در `.gitignore` است.
- اگر توکن ربات جایی به اشتراک گذاشته شد، از BotFather بخواهید آن را ریست (Revoke) کند.

## ساختار پروژه

| فایل | شرح |
| --- | --- |
| `main.py` | نقطه ورود برنامه |
| `gui.py` | رابط گرافیکی (۵ تب: ربات، گروه، دسته‌بندی، دریافت، گزارش) |
| `bale_client.py` | کلاینت API بله (getMe، getUpdates، getChat) |
| `categorizer.py` | موتور دسته‌بندی کلیدواژه‌ای |
| `storage.py` | ذخیره/بارگذاری پیام‌ها + ورود CSV و JSON |
| `report.py` | مولد گزارش HTML راست‌به‌چپ با تاریخ شمسی |
| `jalali.py` | تبدیل تاریخ میلادی به شمسی |

## عیب‌یابی

- **ربات پیام‌های گروه را نمی‌بیند:** ربات را ادمین گروه کنید و در گروه یک پیام جدید بفرستید، سپس «شناسایی گروه‌ها» را دوباره بزنید.
- **پیام قدیمی دریافت نمی‌شود:** طبیعی است؛ سرور بله فقط آخرین ۲۰۰۰ آپدیت را تا ۲۴ ساعت نگه می‌دارد و برنامه باید در حال اجرا باشد. برای گذشته از ابزار بکاپ استفاده کنید.
- **گزارش فارسی به‌هم‌ریخته است:** فایل HTML با کدگذاری UTF-8 ذخیره می‌شود؛ فونت وزیرمتن از اینترنت بارگذاری می‌شود و در صورت قطع بودن، Tahoma جایگزین می‌شود.
